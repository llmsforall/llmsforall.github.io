01 / GETTING STARTED

Bring a project.

Get the package for your platform and follow the release instructions to set up a local model. Then open a terminal in your project.

Get the CLI

Download Millie CLI v0.1.0 for your platform. Follow the installation walkthrough to set up the CLI; first launch lets you choose and download a model.

# Continue an earlier conversation$ millie resume

02 / THE MODELS

Three ways to run Millie.

Choose from three open-weight models with different expert formats and file sizes. Each runs locally with the Millie runtime.

Millie models and approximate model-file download sizes
MODELEXPERT FORMATMODEL FILEAT A GLANCE
7 GB1-bit6.30 GBThe smallest model download.
9 GBTernary8.31 GBThe middle option in file size.
11 GB2-bit10.32 GBThe highest expert precision.

Model-file sizes are approximate decimal GB, not total RAM requirements. Runtime memory also depends on context length and configuration. See the release documentation for hardware requirements.
