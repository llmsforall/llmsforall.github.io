Millie

Capable language models. Small enough to take with you.

Open weights · Text and image input

We trained Millie to retain useful coding and agent capabilities at very low weight precision. These 35-billion-parameter mixture-of-experts models activate about 3 billion parameters per token, with releases of approximately 7, 9, and 11 GB including vision.

Our custom weight formats and inference kernels make these models practical across phones, laptops, and desktops. Millie builds on Agents-A1 and the Qwen3.5 architecture.

Get started with Millie CLI

Run a coding agent locally in your own project. No account or API key required.

Apple silicon (M1 or newer) · macOS 12+ · 16 GB+ unified memory

  1. Open Terminal and install

    Press Command + Space, type “Terminal”, and press Return. Paste the command below, then press Return.

    curl -fsSL https://raw.githubusercontent.com/llmsforall/millie-cli/main/scripts/install/install.sh | sh

    The installer downloads the CLI and its runtime. No compiling or administrator password needed for the default installation.

  2. Activate and check

    Run these commands one at a time. The first makes Millie available in this terminal.

    export PATH="$HOME/.local/bin:$PATH"
    millie --version

    You should see millie followed by the installed version number.

  3. Choose your project folder

    Type cd followed by a space, drag your project folder from Finder into Terminal, then press Return. This selects the folder Millie will work in.

    Use a folder containing the code you want help with. If the folder cannot be found, check its path before continuing.

  4. Start Millie and choose a model

    millie

    Millie recommends a model for your machine. Select one and approve its download. The model is a separate download of several GB; Millie shows the size before asking. Wait for the download and loading to finish.

  5. Try your first task

    When Millie’s input prompt is ready, type:

    Explain what this project does. Don’t change any files yet.

    You can then ask questions, request code changes, or work through a task in the same conversation.

Linux x86_64 · glibc 2.31+ (for example, Ubuntu 20.04+)

Next time

Open Terminal, enter your project folder, and run millie. There’s no need to reinstall: downloaded models are reused. Run millie resume to return to a saved conversation.

Having trouble?

“millie: command not found”

Run the activation command from step 2 again, then check millie --version. If that still fails, follow the installation troubleshooting steps.

Model won’t load or memory is tight?

Close other memory-heavy applications and consult the model and memory guide. GPU placement and context settings affect how much memory you need.

For other problems, report an issue with your hardware, operating system, selected model, and error message, or email us.
